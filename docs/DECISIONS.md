# Продуктовые и технические решения

Короткий журнал решений: что выбрали, почему и от чего отказались.

## 1. Тема: дроби, 5–6 класс

**Решение:** обыкновенные дроби, сеттинг «пиццерия».

**Почему:**
- Дроби — одна из самых трудных тем в 5–6 классе, на ней многие начинают «не понимать математику».
- Дробь естественно показывать визуально: пицца, разрезанная на равные куски, и есть модель дроби. Ученик не заучивает правила, а видит, почему 1/3 больше 1/4.
- Ошибки в дробях хорошо изучены и устойчивы, поэтому их можно распознавать автоматически (см. п. 3).

**Рассматривали:** чат-квест по английскому (без API не работает вообще, демонстрация непредсказуема), «детектив эпох» по истории (много контента и фактчекинга при сроке 24 часа).

## 2. Гибрид: локальная проверка + ИИ

**Решение:** задания с однозначным ответом проверяются в браузере. ИИ используется только для свободных объяснений ученика и итоговой диагностики.

**Почему:**
- Мгновенная обратная связь без задержек и стоимости API.
- Надёжность: тренажёр полностью работает без сети и при сбое API.
- ИИ занят тем, с чем обычный код не справится: понять объяснение школьника своими словами и связать ошибки в общую картину.

## 3. Диагностика заблуждений вместо «верно / неверно»

**Решение:** каждый неверный вариант ответа привязан к коду заблуждения из каталога:

| Код | Заблуждение |
|---|---|
| `DENOM_BIGGER` | «Больше знаменатель — больше кусок» |
| `ADD_ACROSS` | «Складываю числители и знаменатели» (1/2 + 1/3 = 2/5) |
| `NO_COMMON_DENOM` | «Забываю привести к общему знаменателю» |
| `EQUIV` | «Не вижу равные дроби» (1/2 = 4/8) |
| `WHOLE_PART` | «Путаюсь с целой частью» |

**Почему:** ответ «неверно» ничему не учит. Объяснение конкретной ошибки и итоговый «диагноз» показывают ученику, *что именно* нужно исправить в его понимании.

## 4. Обратная связь в две попытки

**Решение:** после первой ошибки ученик видит объяснение этой ошибки и пробует ещё раз. После второй видит решение по шагам, наглядно на пицце.

**Почему:** у ученика есть шанс исправиться самому, но он не застревает и не теряет мотивацию.

## 5. Безопасность ключа API

**Решение:** статический фронтенд на GitHub Pages плюс прокси на Cloudflare Workers. Ключ DeepSeek хранится только в secrets воркера. Прокси принимает запросы только с домена сайта, ограничивает частоту запросов и длину текста.

**Почему:** у GitHub Pages нет серверной части. Ключ во фронтенде увидит любой, кто откроет DevTools.

## 6. Сначала телефон

**Решение:** выбор кусков тапом вместо перетаскивания, крупные зоны нажатия, одна колонка на узких экранах, кнопка «Проверить» всегда в зоне видимости.

**Почему:** школьники чаще всего заходят с телефона, а drag-and-drop на тачскрине неудобен и конфликтует с прокруткой.

## 7. Мотивация без перегруза

**Решение:** монеты-чаевые за верные ответы (больше — с первой попытки, меньше — с подсказкой), звёзды за уровень, рейтинг пиццерии в конце.

**Почему:** лёгкая игровая петля удерживает внимание, но не отвлекает от математики.
